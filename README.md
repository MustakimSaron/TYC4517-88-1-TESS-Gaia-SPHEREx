# Multi-Mission Analysis of TYC 4517-88-1 (TIC 397073349)

**Reproducible Python pipeline, reduced multi-mission datasets, publication figures, and LaTeX manuscript for *INASAN Science Reports*.**

> **Working Title:** *Multi-Sector TESS Photometry, Gaia DR3 Orbit, and SPHEREx DR1 Spectrophotometry of the Unstudied High-Mass-Function Ellipsoidal Binary TYC 4517-88-1 (TIC 397073349)*  
> **Author:** Md Mustakim Bin Alam (Physics Faculty, Novosibirsk State University)

## Overview

`TYC 4517-88-1` (`TIC 397073349` / `Gaia DR3 555926586677752960`; $\alpha = 54.61398^\circ$, $\delta = +79.34350^\circ$, $d = 592.73 \pm 4.17\text{ pc}$) is a bright ($G = 11.53\text{ mag}$), previously unstudied single-lined spectroscopic binary (`SB1`) in Gaia DR3 with a high binary mass function $f(M) = 0.2239 \pm 0.0126\,M_\odot$ ($P_{\rm Gaia} = 2.627959 \pm 0.000060\text{ d}$, $K_1 = 93.95 \pm 1.75\text{ km s}^{-1}$, $e = 0.0767 \pm 0.0266$).

This repository contains the end-to-end Python extraction, time-series analysis, spectral energy distribution (SED) modeling, and figure-generation code (`tyc4517_inasan.ipynb` and `tyc4517_inasan.py`) combining:
1. **NASA TESS** multi-sector light curves across 8 sectors spanning **4.60 years** (`1679.1 d`, $N = 44{,}710$ points; Sectors 25, 26, 52, 53, 59, 73, 79, and 86),
2. **ESA Gaia DR3** astrometry, RVS orbital elements, FLAME stellar parameters, and $60''$ field crowding data,
3. **NASA SPHEREx Data Release 1 (DR1)** All-Sky Spectral Cube spectrophotometry (`100` valid channels across $0.753\text{--}4.988\,\mu\mathrm{m}$, median $\mathrm{S/N} = 413.2$), and
4. **18-band archival photometry** spanning FUV to mid-IR (`GALEX`, `Tycho-2`, `APASS DR9`, `Gaia DR3`, `2MASS`, `AllWISE`) plus `unWISE` infrared imaging and `ROSAT 2RXS` X-ray upper limits.

---

## Key Scientific Findings

* **Refined Orbital Ephemeris & Ellipsoidal Modulation:** TESS photometry detects a phase-locked double-wave ellipsoidal tidal modulation ($A_2 = 1821.3 \pm 71.3\text{ ppm}$ sector mean; $1802.7 \pm 11.6\text{ ppm}$ global fit; phase scatter $\sigma = 5.0^\circ$ over $4.60\text{ yr}$), refining the orbital period to **$P_{\rm TESS} = 2.6278035 \pm 0.0000340\text{ d}$** with no eclipses ($\lesssim 350\text{ ppm}$) and no $\delta$ Scuti pulsations ($\lesssim 58.5\text{ ppm}$).
* **Relativistic Doppler Beaming Veto of a $5\,M_\odot$ Black Hole Impostor:** Under single-star FLAME assumptions ($M_1 = 1.49\,M_\odot$, $R_1 = 2.06\,R_\odot$, $L_2 = 0$), matching $A_2 = 1821\text{ ppm}$ requires $i = 25.0^\circ$ and $M_2 = 5.01\,M_\odot$. However, an undiluted primary moving at $K_1 = 94\text{ km s}^{-1}$ must produce an $831\text{ ppm}$ phase-locked Doppler beaming signal, whereas the coherent RV-projected beaming amplitude across all 8 sectors is only $A_{1,\parallel} = +101.9 \pm 133.1\text{ ppm}$ ($5.48\sigma$ tension; quiet-sector floor $134\text{--}197\text{ ppm}$).
* **Favored Physical Nature:** Combined with a featureless F5V continuum across the 18-band SED and 100-channel SPHEREx DR1 spectrum (median residual $+3.0\%$, $\mathrm{MAD} = 9.3\%$) lacking UV, mid-IR, or X-ray excess, all observables favor a **detached, non-eclipsing, near-equal-mass F+F/G main-sequence binary** ($M_1 \approx 1.32\,M_\odot$, $M_2 \approx 1.37\,M_\odot$, $q \approx 1.04$, $i \approx 58.9^\circ < i_{\rm ecl} = 75.1^\circ$) whose flux dilution reduces $A_2$ and whose opposing radial velocities cancel net beaming to $\sim 37\text{ ppm}$.
* **Tidally Driven Pseudo-Synchronized Starspots:** Pre-whitening $2f_{\rm orb}$ reveals evolving ($134\text{--}853\text{ ppm}$), phase-migrating starspots with per-sector periods $P_{\rm rot} = 2.43\text{--}2.70\text{ d}$ bracketing the Hut (1981) tidal pseudo-synchronization period ($P_{\rm ps} = 2.538\text{ d}$ for $e = 0.0767$).
